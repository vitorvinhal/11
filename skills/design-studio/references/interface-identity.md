# Design de Interfaces com Identidade

**Referência complementar** — adicionar ao workflow da skill `design-studio`
quando o resultado parecer "template" ou genérico.

---

## Quando usar este complemento

- O plano da design-studio gerou algo que serviria para qualquer cliente
- O resultado parece genérico demais
- Precisa de mais estrutura no processo criativo
- O usuário pediu algo com mais personalidade

---

## Princípios Adicionais

### 1. Comece pelo problema, nunca pelo layout

Antes de desenhar qualquer componente, responda:

- O que é este produto?
- Quem vai utilizá-lo?
- Qual é o objetivo desta página?
- O que o usuário deve fazer ao chegar aqui?

Toda decisão visual deve nascer dessas respostas.

### 2. O Hero é a tese da página

A primeira dobra precisa responder: "Por que esta página existe?"

Em vez do padrão automático (título gigante + subtítulo + botão + gradiente),
escolha o elemento que melhor representa o produto:

- uma demonstração funcionando
- uma fotografia
- uma visualização de dados
- uma animação
- um vídeo
- um objeto 3D
- uma ilustração
- apenas uma frase extremamente forte

O Hero deve ser consequência do conteúdo. Nunca do template.

### 3. Tipografia deve ter personalidade

Defina papéis claros:

- **Fonte de destaque**: apenas para impacto. Personalidade, identidade, memorabilidade.
- **Fonte de corpo**: leitura confortável. Quase todo o conteúdo.
- **Fonte utilitária (opcional)**: números, códigos, tabelas, métricas, legendas.

Cada fonte deve existir por um motivo. Nunca apenas porque "fica bonito".

### 4. A estrutura precisa significar algo

Elementos estruturais só existem quando carregam informação.

Exemplos válidos: etapas numeradas, timeline, capítulos, fluxo, fases, hierarquia real.

Evite: linhas decorativas, divisores sem função, números aleatórios, grids apenas estéticos.

Se remover o elemento e nada mudar na compreensão, provavelmente ele não deveria existir.

### 5. Concentre a ousadia

Escolha apenas UM lugar para chamar muita atenção. Todo o restante deve apoiar esse destaque.

Quanto mais elementos tentam ser especiais, menos especial qualquer um deles se torna.

### 6. Copy também é design

- Voz ativa
- Frases curtas
- Nomes consistentes
- Ações claras
- Títulos específicos

Estados vazios, mensagens de erro e microcopy também são design.

---

## Passada de Crítica (antes de implementar)

Quando a design-studio produzir um plano, execute esta segunda passada:

Pergunte:

- Isso poderia servir para qualquer cliente deste tipo?
- Isso parece um template?
- O layout comunica este assunto?
- Existe personalidade suficiente?
- Estou repetindo algo que sempre faço?

Se a resposta for "sim" para qualquer uma, refatore o plano antes de escrever código.

---

## Checklist Complementar

Adicionar ao self-critique da design-studio:

- [ ] O layout parece específico para este produto?
- [ ] Existe uma identidade clara?
- [ ] O Hero comunica imediatamente o propósito?
- [ ] A estrutura faz sentido (não é apenas estética)?
- [ ] Existe apenas um elemento realmente marcante?
- [ ] Os clichês foram usados conscientemente?
- [ ] A interface continua boa sem animações?
- [ ] O texto é claro e específico?
- [ ] Há consistência visual em toda a página?

---

## Regra de Ouro

Nunca desenhe uma interface pensando em "como um site bonito costuma ser".

Desenhe pensando em **como este produto específico merece ser apresentado**.

A estética deve ser consequência da identidade, do contexto e da função.
