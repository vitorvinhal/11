### OpenMontage (AGPL-3.0) — `skills/OpenMontage/`

Sistema agentic de produção de vídeo open-source. Turn o assistente de código num estúdio de vídeo.

- **Pipelines:** animated-explaioner, animation, avatar-spokesperson, cinematic, clip-factory, documentary-montage, hybrid, localization-dub, podcast-repurpose, screen-demo, talking-head, character-animation
- **Estrutura:** `pipeline_defs/` (manifests YAML), `skills/` (skills de direção por stage), `tools/` (100+ tools Python), `schemas/`, `styles/`, `remotion-composer/`, `backlot/`, `lib/`
- **Setup (Windows):** `py -3 -m venv .venv; .\.venv\Scripts\Activate.ps1; python -m pip install -r requirements.txt; cd remotion-composer; npm install; cd ..; python -m pip install piper-tts; Copy-Item .env.example .env`
- Docs: `AGENT_GUIDE.md`, `PROJECT_CONTEXT.md`, `CLAUDE.md`, `docs/PROVIDERS.md`
- Licença AGPL-3.0 preservada em `skills/OpenMontage/LICENSE`
